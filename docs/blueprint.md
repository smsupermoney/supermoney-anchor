# **App Name**: AnchorLink

## Core Features:

- Dashboard Overview: Dashboard with credit limit utilization, invoice statistics, and program performance overview.
- Retailer Management: List of retailers associated with the anchor, including their status, credit assignment, invoices, and disbursal information.
- Invoice Tracking: Module to track the full lifecycle of each invoice with statuses: Initiated, Approved, Sent to Lender, Disbursed.
- Lead Management: Add Lead module for onboarding new retailers, tracking stages from Lead Created to PSD Completed.
- Lender Program View: Program view to show total, used, and remaining credit limits per lender, with invoice and disbursal breakdown.
- Risk Scoring: AI powered tool to provide risk assessment, based on available invoices.

## Style Guidelines:

- Primary color: Deep sky blue (#3498db) to convey trust and reliability.
- Background color: Light gray (#ecf0f1) for a clean and modern interface.
- Accent color: Emerald green (#2ecc71) for CTAs, progress indicators, and success states.
- Body and headline font: 'Inter', a grotesque-style sans-serif font for a modern, machined, objective, neutral look, and suitable for headlines or body text.
- Use flat, line-based icons to represent financial data, progress, and status updates.
- Utilize a card-based layout with tables for detailed data views and filters for easy data management.
- Incorporate subtle animations and transitions to enhance user experience and provide feedback on actions.
